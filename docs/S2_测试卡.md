# S2 测试卡（给用户：配对 + 手机看真实代码）

**这一步验证什么**：手机扫码配对电脑 → 电脑确认 → 手机看到**真实授权项目**
的目录和文件内容；未配对的手机什么都看不到。

**开始前必须完成（安全要求）**：
1. **重新打开 Windows 防火墙**（之前为实验关闭过）。管理员 PowerShell 执行：
   ```powershell
   netsh advfirewall set allprofiles state on
   netsh advfirewall firewall add rule name="PocketCode Server" dir=in action=allow protocol=TCP localport=8765 profile=private,public
   ```
   （只放行 8765 端口的 TCP 入站，不是全关防火墙。）
2. 在电脑管理窗口「添加项目…」选择**一个真实的代码文件夹**
   （建议先选个小的；依赖目录会被自动过滤）。
3. 重启电脑端程序：`powershell -ExecutionPolicy Bypass -File scripts\start-desktop.ps1`

## 测试步骤

| # | 操作 | 预期 |
|---|---|---|
| 1 | 手机打开 App → 「连接」页 | 状态条「未配对」；有「扫码配对」按钮 |
| 2 | 电脑管理窗口点「显示配对二维码…」 | 二维码 + 配对码显示（核对证书指纹与窗口一致） |
| 3 | 手机点「扫码配对」，对准二维码 | 手机提示配对中；**电脑弹出确认框**显示设备名 |
| 4 | 电脑点「允许」 | 手机显示「✔ 已配对：电脑名」，状态条变绿「已连接 · 延迟」 |
| 5 | 电脑点「拒绝」（重新生成二维码再试一次） | 手机明确提示"电脑用户拒绝了这次配对" |
| 6 | 回「项目」页 | 显示真实授权项目名（不是演示数据） |
| 7 | 点进项目 | 显示**真实目录**：文件夹在前、文件在后；`node_modules`/`.git` 等不可见 |
| 8 | 点一个 .py/.md 文件 | 显示只读内容，视觉折行；顶部显示路径/编码/换行符 |
| 9 | 点图片等二进制文件 | 明确提示"二进制或使用不支持的编码"，不显示乱码 |
| 10 | 手机关热点/电脑断网 → 看项目页 | 状态条「离线」；项目/目录显示本地缓存并标注"来自缓存" |
| 11 | 恢复网络 | 约 15 秒自动恢复「已连接」 |
| 12 | 电脑管理窗口「撤销所选设备授权」 | 手机约 15 秒内变离线，且之后所有请求被拒 |
| 13 | 完全关闭手机 App 重开 | 配对仍在（不需重扫），项目列表正常 |

## 故障排查

| 现象 | 处理 |
|---|---|
| 扫码后一直"配对中" | 电脑端确认框可能被挡住，查看任务栏；60 秒未确认按超时处理，重新生成二维码 |
| 提示"证书指纹不匹配" | 电脑端证书被更换（重装等），重新扫码配对即可 |
| 提示配对码无效/已使用 | 二维码过期或已被消费，电脑端关掉重开二维码窗口 |
| 撤销后手机还能用？ | 不会——令牌立即失效；如异常请截图给开发者 |

## 验收通过标准（对应 PRD M0）

已配对手机能读取授权真实项目；电脑修改文件后手机重新进入即可看到最新内容；
未配对设备不能读取任何真实文件。
