# 夜航：继续阅读、离线与修改笔记

交付标识：`1.0-nightfall6` / versionCode 16 / `夜航 · build 2026-11-03-2`。

## 入口与行为

- 长按保留系统文字选择和复制。轻点函数或变量名只记录位置，点击底栏「代码导航」
  才打开定义/引用；选中代码时优先显示复制、分享、旁注，导航禁用。
- 首页新增继续阅读与最近阅读，恢复已有的文件滚动位置；项目显示实际已缓存正文数，
  不再用项目列表缓存冒充整项目可离线。最近记录最多 20 条，界面展示最近 6 条。
- 设置与目录页均可进入缓存管理：文件数量、正文空间估算、目录版本对应情况、
  上次任务和未缓存原因。应用内切换页面不取消任务，支持停止、失败路径重试。
  清理先等待该项目任务停止，并在清理期间禁止新任务；草稿、旁注、配对独立保留。
  没有 Android 后台服务，进程被系统关闭后任务不会继续，已落盘部分保留。
- 草稿箱菜单提供整批 ZIP 备份和从 ZIP/JSON 恢复。恢复前显示份数，确认后只追加，
  同名版本保留、相同版本跳过；损坏备份/目标草稿阻止写入。跨文件恢复若遇磁盘错误，
  明确报告已成功份数，重试跳过已成功版本。备份及解压声明上限 16 MiB，最多 10,000 份。
  备份范围是草稿，不含旁注、缓存或配对凭据。Android 导出复用系统 ZIP 分享；
  用户需在分享目标中完成保存，打开分享面板不等于备份已保存。
- 同一文件的两份草稿可逐行比较；先点一份「选择作比较」，再点另一份「与所选版本比较」。
- 阅读底栏「书签旁注」可标记当前行，或给选中的行写旁注。保存位置、完整行原文和版本；
  文件变化后仅对唯一原文匹配自动定位，否则提示核对原行。编辑、删除旁注均保留错误提示；
  输入未保存时关闭需确认。同文件跳转维护最近 20 个返回位置，跨文件沿用已有返回历史。
- 文件右侧菜单新增重命名、移动（普通文件，4 MiB 上限、父目录需已存在）。目标已存在时
  原子拒绝覆盖，来源版本变化时拒绝；文件位置调整不会修复代码引用。成功后草稿、书签、
  旁注、最近阅读和阅读位置跟随新路径；本地迁移失败提示检查旧位置，不回滚电脑文件。
- 编辑菜单和冲突面板提供「另存为新文件」，先保留本地草稿，再调用已有不覆盖新建接口；
  原电脑文件与草稿保留。文件页明确区分电脑正文、本地缓存、手机草稿和待同步状态。

## 验证与边界

- 本轮验证：24 个手机端测试文件 / 181 项测试通过；桌面端完整回归 176 项收集、
  174 项通过 / 2 项因 Windows 符号链接权限跳过，最终移动服务增量回归 22 通过 / 1 跳过；
  合同检查 33 通过。TypeScript、Vite、Capacitor 同步及 Android App 的 5 项 JVM 测试通过。
  APK 使用本机 Gradle 离线构建；依赖既有 chunk 大小和 Gradle 弃用提示仍存在。
- 最终 APK 元数据核对为 `1.0-nightfall6` / 16，包内 127 个前端资源与最终 `dist`
  逐一校验 SHA-256 相同，未包含浏览器 UI fixture。输出位置为
  `mobile/android/app/build/outputs/apk/debug/app-debug.apk`（约 28.6 MB）。

- 自动化覆盖备份 ZIP 往返、损坏/超限输入、保留旧草稿、部分恢复后安全重试、
  旁注并发写入与原文重定位、移动后的本地记录、缓存统计/隔离清理/跨页继续/精准重试，
  以及首页恢复不绕过鉴权/TLS错误、主动导航和另存为。
- 桌面端覆盖原字节移动、来源版本检查、鉴权/项目权限/路径校验、链接拒绝、
  外部程序抢先创建目标时不覆盖。接口合同、模型、客户端、fixtures 和错误说明同步更新。
- 浏览器使用独立 `127.0.0.1:5175` 假项目数据，在 390×844 检查：继续阅读、
  轻点不弹导航、右键不弹导航、主动按钮打开导航、选区操作、旁注保存后重新进入仍存在、
  缓存管理、整批备份显示下载提示、草稿逐行比较。截图在本目录。
- 浏览器自动化的虚拟剪贴板没有接收到页面 Clipboard API 的内容，无法用该接口核实
  最终系统剪贴板；页面复制返回成功提示。备份 ZIP 的格式及往返由自动化测试验证，
  浏览器下载提示不视为已核实外部文件保存。
- 当前无 Android 设备连接。Android 长按菜单、拖动选区、复制到其他应用、备份文件选择器、
  系统分享保存/恢复、键盘弹出时旁注布局、后台/进程回收后的表现仍待真机验收。
- 使用文件移动新接口前，电脑端需从托盘退出并重新启动，加载本轮服务代码。
