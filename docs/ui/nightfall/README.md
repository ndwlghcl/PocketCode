# PocketCode 夜航 UI 交付说明

用户从三套方案中选定 C「夜航」，希望保留暖墨、哑金、灰绿与细线带来的安静、讲究的气质。本次已将这一方向应用到正式 Android 前端，不调整 Windows 端、API 合同或服务端业务。

版本：`1.0-nightfall1`，versionCode `11`，界面标识 `夜航 · build 2026-10-26-3`。

## 已实现

- **统一基础**：颜色、语法色、圆角、动效等由夜航设计变量控制；统一原创 SVG 描边图标、44px 图标按钮、切换开关与可关闭的操作抽屉。无新增第三方依赖。
- **导航**：项目 / 草稿箱 / 设置。进入项目、代码等子页面隐藏底部导航，保留已有路由和文件访问历史；Android 返回先关闭最上层菜单，再处理编辑、文件和页面返回。标签页切换回到顶部，连接页返回恢复原先滚动位置。
- **项目**：轻量连接状态、细线项目列表、暖金/灰绿/浅紫项目图标；项目名优先，快照和缓存信息次要；离线缓存提示合并，避免重复报错占据屏幕。仍然先进入项目目录，不自动打开旧文件。
- **目录**：统一文件/文件夹图标、本地文件名筛选、Git 和新建图标、全文搜索和多文件分享菜单；深层缩进设有上限，长名称截断。排序和自动同步未改，删除仍经过原有确认及回收区流程。
- **代码**：顶部返回/完成、搜索、编辑/保存、更多；底部大纲和关联。其余操作放在抽屉里，另提供专注模式。保留 CodeMirror 的高亮、选区、视觉折行、诊断、搜索定位、大纲、Python 关联和分享能力。
- **草稿**：名称、文件路径、本机保存状态和时间清晰展示；刷新和清空收进菜单，删除仍有确认，空状态缩短。保存队列、保留草稿、冲突及跨文件返回等业务逻辑沿用现有实现。
- **分享/关联/Git/搜索**：应用相同的设计变量、图标和工具栏；分享预览和关联面板使用统一抽屉。
- **设置**：浅色 / 深色 / 系统模式，背景导入/更换/清除/恢复默认，图片透明度、遮罩强度、模糊三个独立参数，字号实时预览、折行和行号开关，实际应用版本与构建号、连接入口。
- **持久化**：外观与代码设置继续走原生磁盘 KV；折行复用原来的 `pc.ui.wrap` 键。全 App 使用一个外观 Provider，不存在阅读器与设置页各存一份的情况。滑块即时渲染、160ms 合并落盘，退到后台时尝试补写，失败向用户提示。
- **背景**：使用 Android 系统 `ACTION_OPEN_DOCUMENT`，不新增读取相册的广泛权限；导入时复制为应用私有文件，不保留相册 URI。位置在 `getNoBackupFilesDir()/appearance/background.jpg`，排除系统云备份；不发送到电脑或云端。临时输入位于缓存，成功与失败都会清理。
- **图片处理**：原生流式读入，输入上限 64MB，先读取尺寸再采样，处理 EXIF 方向，长边最多 1920px，JPEG 85%，同目录原子替换。取消或失败保留旧背景，解码在后台线程进行，位图最终释放。浏览器开发分支使用 IndexedDB 存储压缩后的 Blob，限 32MB，不写入草稿/缓存键。
- **可读性与交互**：背景图、遮罩、前景面板分别渲染，背景层不拦截触摸，代码始终有独立实底。普通动效约 180–220ms，遵循减少动画偏好；菜单有可访问名称、焦点循环和 Escape 关闭。

代码页合并了原来普通/全屏、阅读/编辑的重复 JSX，现有草稿、网络、冲突处理函数仍保留。新增加的只读诊断入口使用当前显示的正文，不会误检查另一份本地草稿；正文变化后不应用过期诊断结果。

## 验证结果

- 移动端测试：**15 个文件、90 项通过**。包含原有 82 项及新增的外观持久化/数值边界、返回层顺序、只读诊断来源和菜单返回保留编辑缓冲等测试。
- TypeScript 与正式 Vite 构建通过；Capacitor 同步通过。
- Android `gradle assembleDebug --offline --no-daemon` 通过，新 Java 背景插件参与编译。
- 浏览器使用**正式 App 组件**与独立的 `127.0.0.1:5175` 示例缓存进行检查，不使用用户真实配对或草稿。
- 已检查：目录展开和排序、缓存文件阅读、真实 CodeMirror 离线输入、完成编辑再打开后保留输入、代码菜单与设置页共用折行、主题与字号切换、行号显示、背景导入及浏览器刷新后恢复、三个独立背景参数、标签页滚动复位。
- 390px、320px 和较宽浏览器视口检查；窄屏未发现页面或代码工具栏横向溢出。390px 下代码主体约 710px 高（示例缓存提示可见时），导航不占阅读区。
- 运行 `adb devices` 返回空列表。**没有安装或启动到 Android 真机；原生选择器、权限表现、重启恢复、方向/缩放、内存及帧率、中文输入法/软键盘、系统返回、真实分享及在线保存等未做真机验收。** 浏览器行为及编译通过不能替代这些验收。
- Vite 仍有编辑器入口体积提示，Gradle 有现有 flatDir/过时 API 提示；均不影响本次构建通过，未为此升级依赖。

## APK 与运行

APK：`mobile/android/app/build/outputs/apk/debug/app-debug.apk`。必须使用包含新原生插件的完整 APK，单独同步旧 App 的网页资源不能提供背景选择器。

重新构建：

```powershell
cd D:\code\PocketCode\mobile
npm test
npm run build
npm run cap:sync
cd android
gradle assembleDebug --offline --no-daemon
```

普通网页开发：在 `mobile` 运行 `npm run dev`。三套原始对比仍可用 `npm run design:dev` 打开。

隔离界面检查：在 `mobile` 运行 `node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5175 --strictPort`，访问 `http://127.0.0.1:5175/ui-fixture.html`。这个入口只允许开发模式、该主机和端口，向独立浏览器源写入明确的假配对、缓存和草稿后加载正式 App；不进入生产构建。示例配对地址无服务，因此离线和网络失败是预期状态。

## 文件入口

| 文件 | 内容 |
| --- | --- |
| `mobile/src/app/nightfall.css` | 夜航设计变量与渐进式页面样式 |
| `mobile/src/ui/{Icon,Controls}.tsx` | 图标、按钮、开关与操作抽屉 |
| `mobile/src/app/{App,Appearance}.tsx` | 导航、外观唯一状态与背景层 |
| `mobile/src/app/backLayers.ts` | 根返回监听器的弹层分发 |
| `mobile/src/features/settings/SettingsScreen.tsx` | 独立设置页面 |
| `mobile/src/storage/uiPrefs.ts` | 复用旧折行键、外观校验和持久化 |
| `mobile/src/native/background.ts` | 原生背景桥和浏览器开发后备 |
| `mobile/android/app/src/main/java/com/pocketcode/app/PocketCodeBackgroundPlugin.java` | 系统选择、压缩、方向、私有存储与系统栏主题 |
| `mobile/src/features/*` | 各页面呈现改造，沿用原业务函数 |
| `mobile/tests/{appearance,backLayers,fileScreen}.test.ts` | 新增与适配的回归测试 |
