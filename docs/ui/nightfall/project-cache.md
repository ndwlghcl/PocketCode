# 一键缓存项目

版本 `1.0-nightfall3` / versionCode `13`，`夜航 · build 2026-10-26-5`。

## 使用

在线打开项目，在目录页根目录面包屑下点击「一键缓存项目」，无需展开文件夹或逐个打开文件。进度显示已处理数量、新缓存、相同版本复用、跳过、失败与正文容量；「查看未缓存原因」列出前 50 项。

缓存完成后，现有离线阅读、搜索、编辑直接使用同一份缓存。再次点击会读取最新目录，版本一致的文件复用本地内容，其他文件重新下载。这个按钮执行一次缓存，不开启后台常驻下载，也不清理历史缓存。

点击「停止」、离开目录页、断线或撤销授权会停止后续下载；当前最多三个请求等待返回后丢弃未落盘结果，已缓存的文件保留。运行时请留在当前页；尚未承诺系统后台继续下载。

## 范围与实现

- 缓存完整返回的目录树以及可读取的文本正文，复用 `GET manifest`、`GET file`，无需新增 API 或电脑端更新。
- 默认跳过依赖、虚拟环境、构建目录以及常见密钥/凭据文件；二进制和服务端拒绝的格式列为跳过。电脑端本来就过滤的目录不会出现在统计里。
- 单文件上限 1,000,000 字节（也保留原缓存字符上限），本次项目正文合计上限 50 MiB，含复用内容；容量不含元数据与 JSON 开销，不代表整个手机累计缓存上限。超限逐项说明，不标成全量缓存成功。
- 目录若被电脑端截断，界面明确提示只处理返回的部分。单文件移除/读取错误继续其他文件；断线、授权撤销或手机存储写入失败则停止队列，保留已成功的部分。
- `pc.cache.*` 与 `pc.draft.*` 分离，不修改草稿、不向电脑写文件。版本复用按文件 SHA-256 标识判断。
- 缓存写入现在返回成功/失败；浏览器 KV 写入错误向上报告，避免空间不足时误计成功。Android 原有私有文件存储和原子写入逻辑保持不变。
- 主要文件：`features/explorer/{cacheProject.ts,ProjectCacheButton.tsx,ExplorerScreen.tsx}`，`storage/cacheStore.ts`、`native/index.ts`、下载图标与夜航样式、App/Android 版本。
