# 夜航补丁：回收区删除与离线提示闪动

版本：`1.0-nightfall2` / versionCode `12`，`夜航 · build 2026-10-26-4`。

## 修改

- 连接管理 → 电脑回收区：每项增加「永久删除」，底部增加「清空回收区」。单项确认包含路径，目录确认注明含全部内容，清空确认注明涉及所有项目。取消不发请求；离线或操作中禁用按钮；失败保留列表并显示错误。
- 复用已有 `DELETE /v1/trash/{trash_id}` 与 `DELETE /v1/trash`，无需修改电脑端或接口合同。恢复和删除成功后直接移除对应列表项，避免后续刷新失败把已经成功的操作误报为失败。
- 原因：连接每 15 秒读取新的 pairing 对象，App 依赖对象引用重建 client，首页和目录因此重复从缓存开始加载，把缓存命中短暂标为离线。现在按地址、令牌、指纹复用 client，且缓存加载成功不直接等同于离线。
- 项目和目录通过 `lastProbe` 显式保留原来的定时后台更新；在线加载期间不显示离线提示，实际断线或读取失败仍标注缓存。回收区在进入页面/恢复连接时加载，普通探测不会清掉操作反馈。
- 沿用已有界面、配对、草稿、服务端与数据格式，无新增依赖。

修改文件：`mobile/src/app/{App.tsx,theme.css,version.ts}`、`mobile/src/api/client.ts`、`mobile/src/features/{projects/ProjectListScreen.tsx,explorer/ExplorerScreen.tsx,settings/ConnectionScreen.tsx}`、`mobile/android/app/build.gradle`；测试在 `mobile/tests/{client,connectionUi}.test.ts`。
