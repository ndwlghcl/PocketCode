# PocketCode Android UI：阶段一设计探索

历史阶段：三套可交互视觉方案已制作。用户已选定 C「夜航」，正式落地见 [夜航交付说明](../nightfall/README.md)。以下保留设计探索时的范围与验证记录。

## 打开方式

在仓库的 `mobile` 目录运行：

```powershell
npm run design:dev
```

浏览器地址：<http://127.0.0.1:5174/design-preview.html>。仅监听本机，端口固定为 5174。

顶部切换项目、文件浏览、代码阅读、设置、草稿箱；页面同时显示三套设计。
可在“比较”下拉框中只看某个方案。“四页全览”显示 3 × 4 个独立手机画板。
小屏可横向滑动比较，也可切换为单方案。截图目录内是实际浏览器渲染结果，不是真机截图。

## 三套方向

| 方向 | 配色与背景 | 页面组织 | 导航与阅读器 |
| --- | --- | --- | --- |
| A 晴彩 | 奶白、淡紫、蜜桃、鼠尾草绿 | 项目为分离彩卡，文件和设置用轻巧圆角容器 | 胶囊选中态、平直的紧凑阅读工具栏 |
| B 山岚 | 青绿山水插画、暖日光、半透明面板 | 项目集中在通透分组里，背景有连续的可见空间 | 浮岛导航、独立悬浮阅读工具栏；代码采用实底 |
| C 夜航 | 暖墨、琥珀、灰绿、浅紫 | 细线列表，低圆角，集中排列的信息 | 下划线选中态、精简阅读工具栏 |

可以混搭，例如 A 的项目卡、B 的背景和导航、C 的代码工具栏。
所有方案都可以切换浅色、深色、跟随系统，颜色模式并不代表最终设计只能采用某一主题。

## 与现有实现的关系

- 阅读与编辑直接复用 `mobile/src/features/editor/CodeEditor.tsx`，包括真实高亮、视觉折行、选区和编辑能力。
- 文件演示树复用 `sortEntries`，保持目录在前、同类按名称排序。
- 使用统一的原创 SVG 描边图标，无新增依赖或外部字体；山水插画为本地 SVG。
- 项目、目录、代码内容、连接状态、Git 状态、草稿均为固定示例，不表示当前电脑真实状态。Python 内容是根据现有服务结构简化的演示，不是完整原文件。
- 页面外壳与组件在预览目录独立制作；尚未接入 `App`、业务网络、原生 KV、草稿仓储或配对流程。
- 正式 `App.tsx`、`theme.css`、`CodeEditor.tsx`、`uiPrefs.ts`、API、Windows 服务及 Android 工程均未修改。
- 独立构建输出到 `mobile/design-preview-dist`，不覆盖正式 `mobile/dist`。普通 `npm run build` 的入口仍为原 App。

## 可试的交互

1. 点击项目进入目录，展开/收起文件夹，筛选文件名，再打开文件。
2. 阅读器切换编辑模式，搜索内容，打开大纲后定位函数。
3. 更多菜单展示诊断、智能关联、分享、刷新等入口；服务类操作只显示演示提示，不发请求。
4. 底部项目 / 草稿箱 / 设置切换。目录和代码隐藏底部导航；预览的返回按钮按层级返回，编辑时先完成编辑。
5. 草稿菜单经过“删除草稿 → 确认删除”才移除示例，空状态可恢复演示草稿。
6. 设置中切换主题、图片、透明度、遮罩、模糊、字号、折行和行号。主题与背景即时作用于当前预览手机；代码设置在进入阅读页时保持。
7. 菜单支持 Escape 关闭与面板内 Tab 焦点循环。图标有可访问名称和悬停提示。
8. 页面、选中态、按压、抽屉使用约 180–220ms 过渡，支持 `prefers-reduced-motion`。

## 背景演示的边界

图片透明度、背景色遮罩强度、图片模糊是三个独立参数。背景层 `pointer-events: none`，不阻挡交互。

浏览器选择的 JPG / PNG / WebP 使用 object URL，只在这次页面会话里显示；不上传、不写入真实 App 存储。预览限制 12MB，尚不提供生产级解码缩放。所有设置只保留到刷新，方案/全览切换导致画板重建时也会重置；正常切换手机内页面保留。

选定设计后才实现 Android 系统选择器、私有空间持久存储、图片尺寸处理、失败恢复以及复用现有偏好仓储。不能以浏览器演示替代 Android 权限、重启恢复、性能或输入法验收。

## 验证记录（2026-10-26）

- `npm test`：现有移动端 13 个测试文件、82 项测试通过。
- `npm run design:build`：TypeScript 检查和独立预览生产构建通过。
- `npm run build`：正式 App 生产构建通过。
- 浏览器：三方案四主页面及草稿箱均可打开；全览产生 12 个画板。
- 浏览器交互：文件过滤→打开代码、更多菜单→大纲定位、阅读→编辑、深色切换、透明度滑块、行号开关跨页面生效已检查。
- 背景 DOM 检查：图片透明度保持 0.65 时，独立遮罩可改为 0.25，背景层不参与触摸。
- 1280px 比较视口、390px 单方案视口、320px 单方案阅读视口已检查，手机容器和代码工具栏未发现横向溢出。窄视口使用横向比较区。
- 构建会提示 CodeMirror 相关入口体积较大；本次没有为设计预览调整生产编辑器的加载策略。
- 开发中热更新曾出现重复 `createRoot` 警告，已将入口与预览组件拆分，避免组件改动时重复创建根。
- Android 真机、APK、键盘/选区/系统返回、离线恢复、自动同步、诊断/关联/分享真实链路均未在本阶段重新验证。
