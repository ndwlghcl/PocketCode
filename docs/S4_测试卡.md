# S4a 测试卡（给用户：CodeMirror 编辑器 + 阅读位置）

**这一步验证什么**：编辑器从过渡版 textarea 升级为 CodeMirror 6——语法高亮、
行号、折行开关；**阅读位置跨 App 重启保留**（之前挂起的滚动记忆问题在文件
阅读场景的替代实现）；草稿可重命名。**开始前**：电脑端程序运行中、已授权项目。

安装：`mobile\android\app\build\outputs\apk\debug\app-debug.apk`
（S4ef 构建，覆盖安装；连接页底部应显示「S4ef · build 2026-10-25-11」）。

## 测试步骤

| # | 操作 | 预期 |
|---|---|---|
| 1 | 打开一个 Python 文件（行数较多） | 代码有语法高亮（关键字/字符串/注释颜色区分），左侧有行号；界面风格与之前一致（深色模式也看一眼） |
| 2 | 打开一个 .js/.ts/.json/.md 文件 | 同样有对应高亮；不认识的扩展名退化为无高亮但不报错 |
| 3 | 滚到文件中部 → 退出文件 → 重新打开 | 直接恢复到上次读到的位置附近 |
| 4 | 滚到中部 → **完全关闭 App 再打开** → 进该文件 | 阅读位置仍保留（跨重启持久化，这是本次重点） |
| 5 | 阅读模式点「折行：开」 | 变「折行：关」，长行改为横向滚动；再点切回 |
| 6 | 关掉折行 → 关 App 重开 → 打开文件 | 折行偏好保留 |
| 7 | 点「✎ 编辑」→ 改代码 | 行号跟随、有高亮；自动草稿照常（改完等 1 秒看状态行） |
| 8 | 编辑中把某行变得很长 | 默认折行显示，不出现横向滚动条（与阅读一致） |
| 9 | 保存到电脑 → 电脑上确认 | 保存流程与 S3 相同（冲突/离线逻辑未变） |
| 10 | 编辑态点「＋草稿」建两份 → 选中一份点「重命名」 | 改名后下拉里显示新名字；切换草稿内容正确 |
| 11 | 阅读态选中一段代码 → 复制 | 选中高亮正常，能复制（PRD §4.2 选区复制） |

## 已知限制（本阶段如实说明）

- 「阅读位置记忆」现在指**文件内的阅读位置**（CodeMirror 内部滚动容器）；
  目录页的滚动位置记忆（返回目录回到原位）仍挂起未解决；
- 字号设置、代码折叠、文件内搜索替换在 S4 后续增量；
- 语言高亮覆盖常见语言（Python/Java/JS/TS/JSON/HTML/CSS/Markdown 等），
  冷门语言无高亮但不影响阅读；
- 首次打开一个新语言的文件时高亮延迟零点几秒出现（语言包按需加载），属正常。

### S4c/S4d 增补（大纲/符号导航 + Python 诊断）

**前置**：电脑端需重启一次（新端点：diagnose）；电脑端 venv 已装 pyflakes
（未装也能测语法检查，但不会有"未定义名称"告警）。

| # | 操作 | 预期 |
|---|---|---|
| 30 | 打开一个较大的 .py 文件 → 全屏菜单或按钮行点「大纲」 | 底部弹出抽屉，列出 class/函数/方法（方法缩进显示）+ 行号；点任意一条跳到该行并居中 |
| 31 | 跳转后 | 出现「↩ 返回原位置」浮动按钮，点一下回到跳转前的位置 |
| 32 | 打开 .md 文件看大纲 | 标题（#）作为大纲条目 |
| 33 | 打开 .py → 全屏**长按**代码里的一个函数名 | 弹出符号操作单：「跳转定义 / 查找引用 / 复制符号」；普通单击不会触发任何跳转（防误触） |
| 34 | 符号单点「跳转定义」 | 定义只有一处 → 直接跳过去；多处 → 列出选择；本文件没有 → 明确提示 |
| 35 | 符号单点「查找引用」 | 列出本文件所有出现（行号+行内容），点条目跳转 |
| 36 | 编辑一个 .py 文件，故意写坏（如删掉一个冒号）→ 保存到电脑（保存不清草稿）→ 点「⋯」→「检查语法」 | 顶栏下方弹出诊断列表，红 ✘（语法错误）；点条目跳到那一行，**编辑器里该位置有红色波浪线** |
| 37 | 把语法改对，再写一个未定义变量（如 `print(undefined_var)`）→ 再点「检查语法」 | 黄 ⚠ 警告（undefined name，来自 pyflakes）；编辑器黄色波浪线 |
| 38 | 全部改对 → 再检查 | 提示「✔ 检查完成：没有发现问题」 |
| 39 | 断网 → 点「检查语法」 | 按钮不可用（诊断需要电脑；离线明确降级） |
| 40 | 非 .py 文件（.md/.js）编辑 | 没有检查按钮（诊断首版只支持 Python） |

## 故障排查

- 打开文件白屏或无行号：截图连接页 build 标记与文件页；
- 编辑时输入法异常（候选词框位置错乱等）：截屏 + 说明输入法名称；
- 阅读位置不生效：确认步骤 4 里 App 是彻底关闭（从最近任务划掉）而非切后台。
