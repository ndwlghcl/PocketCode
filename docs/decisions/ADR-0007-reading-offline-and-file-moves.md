# ADR-0007：阅读连续性、离线任务与不覆盖移动

日期：2026-11-03。状态：采用。

长按代码交还系统选区菜单；轻点只报告符号，点击「代码导航」才打开定义/引用操作。
书签、旁注和最近阅读独立存在 `pc.reading.*`，不属于缓存；旁注保留完整行原文和
文件版本，版本改变后只对唯一原文匹配自动定位，其余保留原行并提示核对。

缓存任务由应用内单例维护，页面订阅可以取消而任务继续。显式停止、凭据变化、
授权撤销会取消任务；进程被终止后不声称任务仍运行。最终报告保存在
`pc.cache.report.*`，失败路径独立保存以便精准重试。缓存清理仅针对项目正文、
目录和报告，必须等待任务停止；不删除草稿、旁注和配对。

草稿备份为 ZIP 内一份有格式标识和版本号的 UTF-8 JSON，正文含编码、换行、名称、
时间和来源元数据。读取不完整时拒绝导出“完整备份”。恢复前完整校验并预读全部
目标；恢复仅追加、相同版本跳过，不覆盖原草稿。跨文件写入不保证整体原子，存储
失败时报告已成功份数，允许安全重试。备份输入和解压声明上限均为 16 MiB。

新增 `POST /v1/projects/{project_id}/files/move`，来源/目标路径锁按固定顺序获取。
仅普通文件，目标父目录已存在，来源版本检查，路径不经过链接或重解析点。Windows
采用目标存在即失败的 `os.rename`；Linux 使用 `renameat2(RENAME_NOREPLACE)`；
其他不支持的平台返回 `IO_ERROR`，不回退到可能覆盖目标的 replace/rename。
版本检查是乐观并发控制，检查后外部修改仍可能发生；移动不重写正文，不自动调整引用。
移动成功后手机先合并草稿、旁注到新路径再删除旧键；本地迁移失败单独提示，保留
可恢复数据，不尝试反向移动电脑文件。冲突「另存为」复用已有原子不覆盖新建接口。
