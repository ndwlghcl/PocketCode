# ADR-0006：Python 静态关联与跨文件导航

状态：已采用，2026-10-26。

## 背景

S5a 先实现 Python 关联文件推荐、跨文件定义/引用和关联分享。个人学习项目不引入
常驻语言服务器、向量数据库或付费模型；保留现有文件服务、草稿和分享结构。

## 决策

- 新增只读 `POST /v1/projects/{project_id}/python/context`。沿用设备鉴权、项目授权、
  路径校验和错误码；只用标准库 `ast` 解析源码，不执行或导入项目代码。
- 每次请求建立有界索引：最多 500 个 Python 文件、10,000 个目录条目、单文件
  1 MiB、总计 8 MiB、单文件 50,000 次 AST 访问。扫描与解析循环按约 3 秒预算
  尽力中止；同步文件读取/单次解析不可抢占，预算不是严格响应时限。
  默认排除依赖和版本目录，不跟随链接或重解析点。
- `resolved` 表示词法绑定或显式导入可以定位，`candidate` 只表示同名候选。
  支持相对导入、别名、有限重导出、`src/` 和带 `__init__.py` 的嵌套包根；
  模块名冲突、变量遮蔽、动态对象和同一行有歧义时降为候选。
- 结果包含定义、引用、关联原因、文件版本和范围警告。上限为 30 个定义、
  100 个引用、20 个关联文件；超限显式标记 `truncated`，不承诺完整调用图。
- 入口可用电脑正文或显式提交的草稿/缓存快照。其他关联文件来自电脑当前版本，
  不自动合并其他文件的手机草稿。草稿/缓存的 `source_version` 是 UTF-8 文本摘要，
  **不能作为写回电脑的 `base_version`**；电脑文件版本仍使用原始字节摘要。
- 只有点击结果才导航。跨文件切换前落盘本地草稿，保留文件返回历史；导航和
  分享前复核电脑文件版本，变化时要求重新分析。关联分析不写回电脑。
- 分享复用多文件文本包。候选和疑似敏感路径默认不勾选；每个文件注明来源、
  版本和关联原因。用户生成预览后才能复制或调用系统分享，超过正文限额时明确失败。

## 限制与后续

没有运行时类型推断、任意动态导入、完整调用图或离线项目语义索引。引用只包括
本次扫描中识别的 AST 使用，不等于全部引用。离线保留原有单文件导航和草稿能力。
返回编辑页恢复模式与草稿，不承诺精确恢复编辑光标/选区。

S5b 补丁导入和 ChatGPT 直连不在本次交付范围。接口合同、fixtures、两端类型和
测试随新增端点同步；不新增依赖或错误码。
