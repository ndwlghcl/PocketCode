# S0 测试卡（给用户：不需要理解代码）

本阶段验证四件事：**合同可机器校验、桌面管理窗口/托盘可用、桌面自动化测试通过、Android APK 可安装打开**。
本阶段没有任何真实代码读取功能（那是 S2），手机 APK 里显示的是演示数据。

---

## 准备（一次性）

1. 确认已安装 Python 3.11+（`python --version`）和 Node.js 20+（`node --version`）。
   JDK 与 Android SDK 只在构建 APK 时需要（本机已具备）。
2. 如果双击运行 .ps1 脚本被系统拦截，先开一次「允许」：
   按 `Win` 键 → 输入 PowerShell → 打开「Windows PowerShell」→ 执行：
   ```powershell
   Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
   ```
   输入 `Y` 回车。这只需做一次。

## 测试 2：Windows 管理窗口与托盘（约 3 分钟）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 运行 `powershell -ExecutionPolicy Bypass -File scripts\start-desktop.ps1` | 出现「PocketCode 管理窗口」 |
| 2 | 查看窗口 | 五个区块齐全：连接状态 / 已授权项目 / 已配对手机 / 服务设置 / 诊断；连接状态显示「运行中」和 `http://…:8765` 地址 |
| 3 | 看屏幕右下角托盘区（可能藏在 `^` 折叠里），找到蓝色 "PC" 图标 | 托盘图标存在，悬停显示 "PocketCode 服务" |
| 4 | 点托盘图标右键 | 菜单含：打开管理窗口 / 暂停服务 / 退出 |
| 5 | 点「诊断」区块里的按钮「检查本机服务」 | 显示 `✔ HTTP 200 — {"status": "ok", …}` |
| 6 | 点窗口右上角 ✕ 关闭窗口 | 窗口消失但**程序没退出**（托盘还在），并提示已最小化到托盘 |
| 7 | 托盘右键 → 「暂停服务」，再「检查本机服务」 | 状态变「已暂停」，诊断显示 ✘ 连接失败 |
| 8 | 托盘右键 → 「恢复服务」，再诊断 | 恢复 ✔ |
| 9 | 再开一个命令行运行 `python -m pocketcode.main`（先 `D:\code\PocketCode\.venv\Scripts\activate`） | 提示「PocketCode 已在运行」，不会出现第二个窗口 |
| 10 | 托盘右键 → 「退出」 | 托盘图标消失，窗口全部关闭 |

## 常见问题

| 现象 | 处理 |
|---|---|
| 提示「无法加载文件…禁止运行脚本」 | 按上面「准备」第 2 步放开执行策略 |
| 窗口显示「启动失败（端口被占用？）」 | 管理窗口 → 服务设置 → 改端口（如 8899）→ 保存并重启服务 |
| `build-apk.ps1` 报 Android SDK 找不到 | 安装 Android Studio 或设置环境变量 `ANDROID_HOME` 指向 SDK 目录 |
| 首次 APK 构建卡在下载 | 正常，Gradle 首次要从 Google 下载插件；耐心等待或配置镜像（见 docs/BUILD_ENVIRONMENT.md） |
| 手机安装被拦截 | 允许「未知来源」或在文件管理器中选择「仍要安装」 |

## 恢复原状态

- 退出桌面程序：托盘右键 → 退出。
- 删除设置：删除 `%APPDATA%\PocketCode\settings.json`（S0 仅存端口）。
- 卸载手机应用：长按图标 → 卸载（S0 不产生任何本机数据）。
