# S3 测试卡（给用户：手机编辑保存到电脑）

**这一步验证什么**：手机直接修改电脑上的真实文件并保存成功；冲突时不覆盖任何一方；
离线草稿保留；多草稿；新建/删除与回收区恢复。**开始前**：电脑端程序运行中、
已授权真实项目、防火墙保持开启（S2 已配置）。

安装：`mobile\android\app\build\outputs\apk\debug\app-debug.apk`（S3c 构建，覆盖安装；
连接页底部应显示「S3c · build 2026-10-25-5」）。

**重要**：先在电脑上把授权项目里的某个文本文件备份一份（本阶段测试会真的改它）。
恢复手段：电脑端每次保存前自动做了快照（设置目录 snapshots/），回收区可恢复删除。

## 测试步骤

| # | 操作 | 预期 |
|---|---|---|
| 1 | 打开一个代码文件 → 点「✎ 编辑」 | 进入编辑：出现草稿栏和 textarea |
| 2 | 随便改一行，等 1 秒 | 状态行显示「有未保存修改（已自动存为本地草稿）」 |
| 3 | 完全关闭 App 再打开 → 进该文件 → 点编辑 | 改动还在（草稿跨重启保留） |
| 4 | 点「保存到电脑」 | 状态「✔ 已同步到电脑」；**在电脑上打开该文件确认内容真的变了** |
| 5 | 电脑上用记事本改同一文件并保存 → 手机再点「保存到电脑」 | 红色冲突框「电脑上的文件已被其他程序修改」，**没有任何一方被覆盖** |
| 6 | 冲突框点「覆盖电脑文件」→ 确认 | 保存成功；电脑内容 = 手机内容（旧内容有快照） |
| 7 | 重做一次冲突 → 点「放弃修改，加载电脑版」 | 手机显示电脑最新内容，草稿清除 |
| 8 | 断开热点 → 编辑文件 → 点「保存到电脑」 | 提示"离线，草稿已保留"；退出再进改动仍在 |
| 9 | 恢复网络 → 「保存到电脑」 | 保存成功 |
| 10 | 编辑中点「＋草稿」命名「实验 A」→ 下拉切换 | 两份草稿独立保存、可切换 |
| 11 | 编辑态按手机返回 | 退出编辑但草稿保留（再进编辑内容还在）；阅读态按返回才回目录 |

### 新建 / 删除 / 回收区（S3c 增补）

| # | 操作 | 预期 |
|---|---|---|
| 12 | 目录页点「＋ 文件」→ 输入名字（如 `笔记.txt`） | 提示「已创建」；**电脑上该目录真的出现空文件**；列表刷新可见 |
| 13 | 点「＋ 文件夹」→ 输入名字（如 `docs`） | 电脑上出现空文件夹；手机列表出现可展开的文件夹行 |
| 14 | 再建一个同名文件 | 红色错误「目标已存在」，电脑上没有多出文件 |
| 15 | 点某文件行右侧 🗑 → 确认 | 该文件从列表消失；**电脑上文件真的不见了** |
| 16 | 打开右上角「⚙ 连接」→ 拉到「电脑回收区」 | 刚才删除的文件在列表里（原路径 + 删除时间） |
| 17 | 点该条目的「恢复」 | 提示「已恢复到 …」；**电脑上文件回来了**；目录页刷新后重新出现 |
| 18 | 电脑上手工新建同名文件占住位置 → 手机再恢复同一条目 | 提示「原位置已被占用，未恢复」，电脑两边内容都没被覆盖 |

### 桌面端历史版本恢复（S3c 增补，在电脑上操作）

| # | 操作 | 预期 |
|---|---|---|
| 19 | 电脑管理窗口 →「历史版本（覆盖前快照）」区块 → 选项目 | 列出被手机覆盖保存过的文件（测试步骤 6 覆盖过的文件应出现） |
| 20 | 选文件 → 选一份旧快照 → 点「恢复所选快照到原文件」→ 确认 | 提示成功；**用记事本打开该文件，内容变回旧版本**；快照列表多一份（恢复前内容自动入快照） |

## 已知限制（本阶段如实说明）

- 编辑器是过渡版（无语法高亮/行号，视觉折行正确）——CodeMirror 6 在 S4 升级；
- 冲突时暂无并排 Diff 视图（S4）；
- 草稿存在应用本地存储，导出/备份功能在 S4；
- 新建入口在项目根目录层（文件名可带子路径，如 `docs/笔记.md`，父目录不存在会自动创建）；
- 回收区恢复只能恢复到原位置；原位置被占用时需先在电脑上处理同名文件；
- 滚动位置记忆仍未生效（挂起中，见交接文档 §5）。

## 故障排查

- 保存报 409 以外错误：截图连接页与错误文字；
- 新建/删除按钮灰色：确认手机在线（顶部状态栏绿点）且未被撤销授权；
- 回收区读取失败：回连接页点「刷新回收区」，仍失败则截图错误文字；
- 想验证快照恢复：按上面第 19-20 步在电脑管理窗口操作。
