# 文件安全、独立草稿与冲突差异

本轮落实用户确认的顺序：新建不覆盖、草稿错误与串行保护、草稿独立编辑、冲突 Diff。版本 `1.0-nightfall4` / versionCode 14，界面标识 `夜航 · build 2026-10-27-1`。

## 完成内容

### 新建文件

先把内容写入同目录临时文件并刷盘，再用 `os.link` 发布完整文件。目标存在时文件系统原子拒绝，返回 409 `ALREADY_EXISTS`；临时文件始终清理。新建目录的竞态也映射为 409。接口复用保存接口的路径锁，但防止 IDE 抢先创建依靠文件系统操作，不依靠服务内部锁。

不支持硬链接的文件系统会失败，不会回退到可能覆盖目标的替换操作；本机 NTFS 已通过测试。原有“保存已存在文件”的乐观并发窗口不属于这项新建修复，仍不能宣称跨进程比较与替换是一个原子操作。

### 草稿存储

只有存储键不存在才返回空草稿。读取异常、JSON 损坏、字段不完整或重复 id 都报错；不能过滤无效项后写回，从而丢弃原数据。每个存储实例共用一条事务队列，覆盖读取、更新、切换、重命名、删除与清空，跨页面操作也有确定顺序；失败不会堵死后续任务。

草稿箱可显示其他可读记录并明确提示部分读取失败；异常记录保持原文。浏览器磁盘 KV 的读取、删除和枚举也不再吞掉异常，缓存层仍自行处理可降级错误。文件页的首次草稿恢复和各操作都捕获并显示错误；本地草稿未成功落盘时不会继续向电脑提交正文。

新草稿保存真实来源的编码、换行与项目名，更新保留已有元数据；旧版草稿仍可读，缺省编码不凭空补成来源信息。

### 本地草稿独立编辑

新增 `DraftEditorScreen`，直接使用草稿自己的内容与身份，不伪造电脑文件响应。取消配对、撤销授权、项目移除或没有文件缓存，都可打开本地草稿编辑、自动/手动保存及导出全文（系统分享，或复制回退）。网络读取项目名与本地草稿列表分开，电脑请求慢不会阻塞列表。

返回前先保存，保存失败保留编辑缓冲并停留页面，仍可导出。用户主动打开来源时，先存本地，再重新核对项目授权并读取真实文件；来源失效、只读或读取失败不丢弃草稿。来源可用时进入原文件页检查、保存，保留原有版本冲突检测。根导航允许授权撤销后访问草稿箱。

### 冲突差异

冲突首先提供「查看差异」，实时读取电脑版本，与当前编辑缓冲做逐行比较；显示增删标记、两边行号与邻近上下文，不修改任何正文。提供「保留草稿，继续编辑」。覆盖降为次级，仍需确认；放弃当前草稿也需确认，且先读取电脑成功再删除当前草稿。

比较后的覆盖使用本次读取的版本号，电脑再修改时仍返回冲突。比较算法限制 LCS 矩阵规模；大变更按整段增删显示，界面最多展示 800 行差异及上下文并注明限制。三方合并/自动合并/冲突另存为未在本轮实现，也未新增基线正文持久化。
