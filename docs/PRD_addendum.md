# PRD 补充记录（v1.1 之后的用户确认需求）

本文件只收录用户在开发过程中明确确认的新增需求；原始 PRD（PRD_v1.1.md）保持
原样不动，避免多会话协作时篡改需求真源。

## ADD-3 · 阅读连续性、草稿备份与离线管理

- **提出与确认**：2026-11-03，用户确认长按用于选中复制，代码导航改成主动点击，
  并要求实现讨论中的设计优化。
- **范围**：首页继续阅读/最近文件、实际缓存情况与管理、跨页面缓存与失败重试、
  草稿整批备份恢复/版本比较、书签旁注/跳转返回历史、文件重命名移动/冲突另存为、
  文件来源和本机保存/待同步状态。
- **交付说明**：[阅读与离线工作区](ui/reading-workspace/README.md)。沿用夜航样式，
  不引入新的顶层导航；数据安全语义见 [ADR-0007](decisions/ADR-0007-reading-offline-and-file-moves.md)。

## ADD-2 · 多文件 ZIP 分享与文件夹整组选中

- **提出与确认**：2026-11-03，用户要求多文件分享增加压缩包选项，并能直接选中某文件夹下的全部文件。
- **实现**：保留文本包，新增 ZIP；文件夹一键递归选中/取消，支持部分选中状态；全选覆盖全部筛选结果，不受 400 项渲染上限影响。
- **交付说明**：[ZIP 分享说明](ui/sharing-zip/README.md)。

## ADD-1 · 阅读与编辑界面支持横竖屏手动切换

- **提出与确认**：2026-10-25，用户提出"后续需要支持代码阅读和编辑界面的横竖屏手动切换"。
- **需求内容**：代码阅读页与编辑页允许用户手动切换横屏/竖屏显示，而不是只跟随
  系统自动旋转；切换时保持阅读位置、光标与未保存草稿不丢失。
- **落地阶段**：S2 阅读器实现时首次交付（含系统自动旋转 + 手动锁定切换）；
  S3 编辑器沿用同一机制。
- **S0/S1 基线**：所有界面在两种方向下不得崩溃、不得错位（已真机验证：
  演示界面横屏正常，2026-10-25）。
- **实现提示**：Capacitor 屏幕方向控制需原生插件（如 @capacitor/screen-orientation），
  引入时同步评估 Android 清单 `screenOrientation` 与 `configChanges` 设置
  （当前清单已含 orientation/screenSize 等 configChanges，旋转不重建 Activity）。
